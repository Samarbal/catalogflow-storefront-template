# CatalogFlow — قالب كتالوج منتجات مع استفسارات عبر واتساب

قالب واجهة متجر للمشروعات الصغيرة، يعرض المنتجات ويسمح للزائر بالبحث والتصفية، مشاهدة التفاصيل، وتجميع المنتجات في سلة قبل إرسال **استفسار طلب** عبر واتساب. يعمل دون خادم أو قاعدة بيانات أو بوابة دفع.

**LUNA Parfums متجر تجريبي خيالي، وليس مشروعًا لعميل حقيقي.** الصور أدناه نماذج توضيحية للعرض وليست لقطات حرفية من التطبيق. راجع [حقوق الأصول](ASSETS.md) قبل استخدام صور المنتجات في مشروع تجاري.

## ما يقدمه القالب

- واجهة متجاوبة للحاسوب والهاتف، مع العربية والإنجليزية واتجاهي RTL وLTR.
- كتالوج قابل للبحث والتصفية حسب الفئة والسعر، مع صفحة تفاصيل لكل منتج.
- سلة تفاعلية تحفظ محتواها في متصفح الزائر وتعرض الإجمالي التقديري.
- رسالة استفسار واتساب محلية اللغة تحتوي المنتجات المختارة والكميات والعملة والإجمالي التقديري.
- إعدادات منفصلة لهوية النشاط، الألوان، المنتجات، المحتوى، العملة، ورقم واتساب.

## كيف يعمل واتساب؟

1. يختار الزائر المنتجات والكميات، ثم يراجع السلة والإجمالي التقديري.
2. يظهر تنبيه قبل زر واتساب: العرض التجريبي ليس عملية شراء حقيقية، والاستفسار لا يصبح طلبًا مؤكدًا إلا بعد تأكيد صاحب النشاط.
3. عند الضغط على الزر تُفتح **مسودة** في واتساب برسالة جاهزة للمراجعة. **لا يرسل الموقع الرسالة تلقائيًا.**
4. في نسخة LUNA التجريبية تبدأ الرسالة بـ `طلب تجريبي - CatalogFlow Demo` بالعربية أو `Demo Order - CatalogFlow` بالإنجليزية، وتنتهي بتوضيح أنها تجربة وليست شراءً حقيقيًا.

رقم الوجهة، تفعيل واتساب، نصوص الرسالة، ووضع العرض التجريبي موجودة في `src/config/store.ts`. يمكن إبقاء `isDemo: true` مع `whatsapp.enabled: true` لعرض مسودة تجريبية. عند تجهيز متجر حقيقي، تحقّق من ملكية رقم النشاط واكتب الرقم الدولي بأرقام فقط دون `+` أو مسافات، واستبدل جميع بيانات LUNA والصور التجريبية، ثم اضبط `isDemo: false`. يظل تأكيد التوفر والتوصيل والسعر النهائي مسؤولية النشاط التجاري.

لا يتضمن القالب دفعًا إلكترونيًا، إدارة مخزون، لوحة تحكم، حسابات عملاء، أو سجل طلبات. السلة محفوظة محليًا في المتصفح فقط.

## التشغيل والفحص

يتطلب Node.js 22 وpnpm 10.34.3؛ راجع `.mise.toml` و`package.json`.

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm dev
corepack pnpm typecheck
corepack pnpm test
corepack pnpm format:check
corepack pnpm build
```

ناتج البناء الثابت في `dist/`، وهذا المجلد مستبعد من Git. إعداد فهرسة محركات البحث للعرض الخيالي معطّل في `.figma/make/site.json`.

## تخصيصه لعميل جديد

اتبع [CLIENT_SETUP.md](CLIENT_SETUP.md). بيانات النشاط في `src/config/store.ts`، الترجمات في `src/content/copy.ts`، والمنتجات في `src/data/products.ts`. راجع [ASSETS.md](ASSETS.md) لمصادر الصور وحدود استخدامها. لا يحتاج التخصيص المعتاد إلى تعديل منطق التفاعل في `src/App.tsx` أو `src/lib/`.
